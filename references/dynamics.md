# 动力机制手册：沿时间轴推演

## 一、先把静态图变成动态

模型是快照，动力机制是影片。**必须推到三四个回合之后**：
第一圈往往是假象，第三圈才见结构。

推演时只在三种量上做文章：**存量**（积累）、**流量**（每期进出）、**延迟**（多久才生效）。

## 二、六种模式：先归类，再推细节

| 模式 | 形态 | 成因 | 典型误判 |
|---|---|---|---|
| 增长 | 越转越快 | 正反馈闭环 | 把早期线性增长外推成永久增长 |
| 衰减 | 越转越慢 | 负反馈（体验、口碑） | 以为是执行力问题，实际是结构在拖 |
| 趋近上限 | 先快后停 | 目标型负反馈 | 停滞后继续加投入，边际为零 |
| S 曲线／生命周期 | 慢—快—平—落 | 存量容量有限 | 在「平」的阶段还按「快」的预算做事 |
| 振荡 | 来回摆动 | 作用与反作用之间有延迟 | 越管越乱，加大力度反而放大振幅 |
| 相变 | 突然换运行方式 | 存量越阈值／前提被替换 | 用旧模型解释新状态，得出「这次不一样」 |

## 三、存量与流量：最容易搞混的一对

| | 存量 | 流量 |
|---|---|---|
| 定义 | 累积量，某一时点的状态 | 每期的进出量 |
| 例子 | 信任、用户基数、品牌、体内负荷、现金余额、技能 | 本期新增、本期流失、本期投入、本期消耗 |
| 特征 | 变化慢；越攒越关键；有阈值 | 变化快；容易被短期手段拉动 |
| 对应策略 | 只能靠时间和持续输入改变 | 可以靠一次活动短期拉动 |

**判据**：如果一个指标「今年投得多就今年见效」，它是流量；如果它「要靠几年攒，但攒起来很难被抢走」，它是存量。

**常见错误**：用流量手段解决存量问题——信任不足就加大广告、口碑差就多发优惠券。
短期数字会好看，存量的方向没变。

## 四、非线性：不要线性外推

| 关系 | 形态 | 例子 |
|---|---|---|
| 线性 | 投入翻倍、产出翻倍 | 少见，只在远未饱和时短暂成立 |
| 凸（边际递减） | 先快后慢，可能转负 | 规模与利润率、加班与产出、剂量与效果 |
| S 形 | 慢—快—慢 | 学习曲线、渗透率、技术扩散 |
| 阈值型 | 不到点没反应，过了点突变 | 存量越界、信任崩塌、法规红线 |

**做法**：写出「投入—产出」的拐点在哪，而不是假设一条直线。

## 五、作用与反作用：别只算自己那一半

任何动作都会引来回应。三种常见结构：

1. **对称反制**：你降价，他跟降 → 双方利润同时下降，份额不变（消耗战）。
2. **错位反制**：你降价，他不跟价，改做服务 → 战场被换掉。
3. **延迟反制**：对方要过一两期才反应 → 你会误判「这招有效」，然后加大力度，等反作用到达时振幅被放大（振荡的根源）。

**做法**：每写一个动作，强制写一行「对手／合作者／影响者会怎么回」。

## 六、多主体视角：逐个坐过去

对五类角色各问三句：

- 他看到我这一步，第一反应是什么？
- 他手里有什么我没有的资源？
- 他做什么会让我的方案失效？

**注意**：不需要预测准确，只需要让模型里出现「别人的反应」这一项。
缺了这一项，推演得再细也是单人游戏。

## 七、三个关键点

### 拐点

关键因素发生迁移的时刻。找法：问「现在最稀缺的是什么」，再问「什么情况下它不再稀缺」。

例：从「拼性能」转向「拼成本」，从「拉新」转向「留存」，从「铺渠道」转向「控履约」。

### 相变

运行方式整体改变，通常由两类契机触发：

1. 存量越过阈值（口碑、负债、疲劳、渗透率）
2. 关键前提被替换（技术换代、规则改变、关键人物离场）

**判据**：相变前后，同一套动作的因果方向会变。原来的正反馈可能变成负反馈。

### 本源动力

位于最深层次、变化最慢的存量。识别方法：

- 它是「越攒越多」的那个量
- 它变化很慢，慢到日常看不见
- 表层的剧烈波动，往往只是它越过了某个点

例：一次争吵是导火索，积压的不满才是本源动力；一次宕机是导火索，长期欠下的技术债才是本源动力。

## 八、验证：能不能讲成故事

把推演写成一句话结构：**「谁，因为什么，做了什么，结果如何」**。

- 讲得圆 → 角色齐、因果通、时间顺序对
- 讲不圆 → 缺角色、缺反馈、或缺延迟
- 讲得圆但平淡 → 大概率只是把现象复述了一遍，没有触及本源动力

故事讲完，再问一句：**这个故事里，哪个环节是我最没把握的？** 那个环节就是下一步要验证的东西。
