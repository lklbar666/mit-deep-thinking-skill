# 日常训练：五个可执行动作

## 一、五分钟标题推演（每天）

拿一条新闻标题，**读正文之前**做三步：

1. 猜模型：谁和谁在什么关系里？五类角色各是谁？
2. 猜动力：三个月后会怎样？三年后呢？属于六种模式里的哪一种？
3. 再读正文，只找一件事——**有没有你没想到的角色**

**判据不是猜对情节**，而是发现自己漏了哪类角色。
连续做两周，你会开始在看新闻时自动补角色。

## 二、攒「雏形库」

把见过的结构存成模板，遇到新问题时直接调取比对。建议至少攒这几类：

| 雏形 | 结构 | 识别信号 |
|---|---|---|
| 扩张失速 | 增长 → 稀释品质 → 口碑降 → 流失 → 更依赖扩张 | 越开越快，越开越差 |
| 网络效应 | 用户多 → 价值高 → 用户更多 | 早期慢，过临界点后陡增 |
| 削掉瓶颈 | 去掉一个限制性部件，整体性能跃升 | 长期被某个小环节卡住 |
| 零和僵局 | 一方所得即另一方所失，结构不变则反复重演 | 谈了很多轮，方案都在分同一块蛋糕 |
| 延迟振荡 | 动作 → 延迟 → 反作用 → 过度纠正 | 越管越乱，振幅越来越大 |
| 存量越阈 | 缓慢积累 → 越过阈值 → 突然换状态 | 长期没事，忽然全面爆发 |

攒雏形的价值在于**类比**：新问题往往和旧结构同构，只是名词不同。

## 三、让思维可视化

- 用大画布，不用小本子。模型一开始总是不完整的，需要反复涂改。
- 约定图形语法：方框=事实，圆圈=假设，箭头=因果，星号=关键点，方括号=存量。
- **关键是批判性地看自己的图**，不是画得漂亮。只为「理清思路」而画，会变成给自己的观点找证据。
- 画完问三句：缺谁？哪条箭头其实不成立？哪里只是相关不是因果？

## 四、拿观点去碰撞

1. 先用三句话讲清你的模型（不讲细节，讲结构）
2. 请对方只做一件事：指出他觉得最不成立的那条因果
3. 不要辩解「但是」；把它记成「在什么条件下我错了」

**注意**：碰撞的目的是暴露盲区，不是说服对方。频率适度，别把身边人变成审稿人。

## 五、磨历史观与解无解问题

**历史观**：读长周期的东西——产业变迁、帝国兴衰、技术扩散。
看的不是故事，是「什么量在缓慢积累，然后在哪个点改变了运行方式」。
这直接训练「本源动力」与「相变」的直觉。

**无解问题**：定期挑一个没有标准答案的问题，写一页自己的立场与理由。例如：

- 十年后这个行业还需要现在这个岗位吗
- 一项技术普及到某个程度后，谁的利益会受损
- 一个看似公平的规则，实际在奖励什么行为

**为什么有效**：有标准答案的问题可以靠检索解决，无解问题只能靠建模。
练的是「在没有外部答案时，仍能搭出一个可被检验的结构」。

## 六、训练节奏建议

| 频率 | 动作 | 耗时 |
|---|---|---|
| 每天 | 一条标题推演 | 5 分钟 |
| 每周 | 攒一个雏形，写进库 | 15 分钟 |
| 每两周 | 找一个真问题，走完整四步 | 1–2 小时 |
| 每季度 | 挑一个无解问题，写一页立场 | 1 小时 |

重点不在次数，在**每次都留下可复查的产物**：一张图、一段故事、一条判据。
