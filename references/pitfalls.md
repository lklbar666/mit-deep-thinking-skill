# 九定式自检表

用法：动手前认领 1–2 条最像自己的；复盘时再认领一次，看是不是同一条。

## 入门级

### ① 把现象当原因

| | |
|---|---|
| 表现 | 「累→该休息」「销量跌→该促销」「他不配合→该换人」 |
| 为什么错 | 现象是结果。以结果当原因，等于把问题按回原位 |
| 破法 | 追问上一环：什么导致了「累」？什么导致了「跌」？ |
| 反例 | 累了可能是目标感缺失，也可能是身体问题；休息解决不了这两种 |

### ② 停在通用答案

| | |
|---|---|
| 表现 | 「加强管理」「提升效率」「聚焦用户价值」 |
| 为什么错 | 换个主语也成立，说明它没有指向任何具体结构 |
| 破法 | 把主语换成同行／对手，若毫无违和，就是通用解 |
| 反例 | 「提升复购」对任何零售都成立，因此它对谁都不构成方案 |

## 进阶级

### ③ 把框架当答案

| | |
|---|---|
| 表现 | SWOT 填满四格就收工；2×2 画完就算分析完 |
| 为什么错 | 框架只负责整理信息，不产生因果 |
| 破法 | 每个格子后面追问「所以呢」「为什么会这样」 |
| 反例 | 把优势劣势列全，仍然不知道明年该做什么 |

### ④ 用归类代替解释

| | |
|---|---|
| 表现 | 「因为他是理科生」「因为是中小企业」「因为是行业惯例」 |
| 为什么错 | 归类回答的是「属于哪类」，不是「为什么发生」 |
| 破法 | 在同类里找反例——同类中一定有人不这样 |
| 反例 | 中小企业也有招人顺利的；理科生也有不较真的 |

### ⑤ 用关键词结束思考

| | |
|---|---|
| 表现 | 「要做差异化」「要找第二曲线」「要建护城河」 |
| 为什么错 | 关键词是结论的标签。说出标签，大脑就误以为已经完成推理 |
| 破法 | 要求自己用一句不含该词的话，说清具体做什么 |
| 反例 | 「差异化」不能告诉你明天改哪个功能 |

### ⑥ 死守第一个假设

| | |
|---|---|
| 表现 | 对话里高频「但是／然而／可是」，把反例当攻击 |
| 为什么错 | 假设本该随新信息进化；守住它等于关掉输入 |
| 破法 | 把反例写成「在什么条件下我错了」，再去验证那个条件 |
| 反例 | 对方说「别人成本更低也能赚钱」，这正是把假设推进一层的入口 |

## 入口级

### ⑦ 忘了为什么开始

| | |
|---|---|
| 表现 | 资料越收越多，分析越做越细，忘了要回答什么 |
| 为什么错 | 过程本身有成就感，容易替代目的 |
| 破法 | 每 20 分钟问一次「这是为回答哪个问题」 |
| 反例 | 做出 80 页分析，最后说不出结论 |

### ⑧ 用流程冒充思考

| | |
|---|---|
| 表现 | 被问「客户要什么」，答「我去做个问卷」 |
| 为什么错 | 流程保证动作发生，不保证答案产生 |
| 破法 | 先给一个可被推翻的假设，再说怎么验证它 |
| 反例 | 「我猜客户卡在响应速度，不是价格——下周用十个电话验证」 |

### ⑨ 把判断权交出去

| | |
|---|---|
| 表现 | 「您说得对」「那就按领导说的」 |
| 为什么错 | 没有自己的判断，就无法发现别人判断里的漏洞 |
| 破法 | 先写下自己的结论与依据，再去听；听完记录「我改了什么、为什么」 |
| 反例 | 全盘附和的人，在方案失败时也无法解释失败在哪 |

## 一页速查

```
我是把现象当原因了吗？      → 追问上一环
这个答案换个主语还成立吗？  → 成立则太通用
我在用框架代替推理吗？      → 每格追问「所以呢」
我在用归类解释因果吗？      → 同类里找反例
我用关键词收尾了吗？        → 换成一句具体动作
我在守第一个假设吗？        → 把反例写成条件
我忘了要回答什么吗？        → 重述问题
我在讲流程吗？              → 先给假设
我把判断权交出去了吗？      → 先写自己的判断
```
