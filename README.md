# 麻省理工深度思考法 · 操作手册

把「想得深」拆成四步可执行动作：**建模 → 读动力 → 找支点 → 行动反馈**。
核心公式一句话：**本质 = 模型 × 动力机制**。

## 它解决什么

| 你的处境 | 它会怎么帮 |
|---|---|
| 同一个问题反复出现 | 找出让它反复的结构，而不是再解一次现象 |
| 方案都合理但没效果 | 检查是不是只动了现象，没动模型 |
| 说不清哪里不对 | 用五类角色把结构画出来，缺口会自己显形 |
| 多方博弈 | 逐个站到对手位置，推三四个回合 |

## 它不做什么

- 不查事实、不算数字
- 不给「立刻能用」的结论
- 不保证结论正确——它保证的是**你能看出结论建立在什么之上**

## 四步长什么样

```
① 建模      五类角色（输入/输出/竞争/合作/影响者）+ 层次 + 只留因果
② 读动力    六种模式（增长/衰减/趋近上限/S曲线/振荡/相变）+ 存量流量 + 作用反作用
③ 找支点    查前提 / 原因不在旁边 / 扩范围 / 抬视角 / 先定判据
④ 行动反馈  最小可验证动作 → 判断错在哪一层 → 回对应步骤
```

## 五分钟就能试一次

拿今天一条新闻标题，先别读正文：

1. 猜它的模型：谁和谁在什么关系里
2. 猜它的动力：三个月后会怎样，三年后呢
3. 再读正文，只找一件事——**报道里有没有你没想到的角色**

这不是阅读理解训练，是建模训练。重要的不是猜对情节，而是发现自己的盲区。
